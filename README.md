# Carte des incidents du métro de Montréal

Site public : https://evelynebrie.github.io/carte_pannes_metro_site/

Tableau de bord d'une seule page sur les incidents du réseau du métro de
Montréal : carte du réseau, nombre d'incidents, heures d'arrêt, taux pour
100 heures de conduite, répartition horaire, et classements par station,
par tronçon et par cause.

**Source des données** : [Incidents du réseau du métro](https://donnees.montreal.ca/dataset/incidents-du-reseau-du-metro),
données ouvertes de Montréal (STM), et horaires planifiés GTFS de la STM.
Fond de carte : Esri, OpenStreetMap.

Ce dépôt ne contient que le site publié. Le code qui récupère les données et
construit le fichier lu par la page vit dans un dépôt séparé.

Créé par Evelyne Brie, professeure adjointe en science politique à
l'Université de Montréal.
